# 数学题目生成器

这是一个基于 Tkinter 的数学题目生成器，可以生成带括号的加减法练习题并保存为PDF格式。

## 功能特点

- 生成多种类型的数学题：加法、减法、乘法、除法（带余数）、混合运算
- 支持自定义数字范围（1-999）和结果范围（1-999）
- 支持自定义页数、列数和每列题目数（每列最多20题）
- 支持调节字号大小（12-24pt）
- 智能调整行间距，根据字号和题数自动优化
- 实时预览总题数
- 自动生成PDF文件，支持多列排版（1-5列）
- 直观的图形界面操作
- 智能范围验证，确保生成的题目符合设定要求
- 括号位置控制：可独立开关等号左边和右边的括号
- 减少整十数字（10、20、30等）在加减法中的出现频率

## 安装依赖

```bash
pip install -r requirements.txt
```

## 使用方法

### 图形界面版本
```bash
python main.py
```

在界面中：
1. 选择题目类型（加法、减法、乘法、除法、混合运算）
2. 设置数字个数（2个或3个）
3. 设置数字范围（最小值和最大值，范围1-999）
4. 设置结果范围（最小值和最大值，范围1-999）
5. 设置要生成的页数
6. 设置每页的列数（1-5列）
7. 设置每列的题目数量（1-20题）
8. 调节字号大小（12-24pt）
9. 设置括号位置（等号左边 / 等号右边）
10. 可选减少整十数字出现频率
11. 选择保存路径
12. 点击"生成数学题"按钮

## 文件说明

- `main.py` - 主程序入口
- `ui_generator.py` - Tkinter 图形界面生成器
- `math_engine.py` - 数学表达式生成引擎
- `pdf_generator.py` - PDF 文档生成器
- `constants.py` - 全局常量定义
- `requirements.txt` - 依赖包列表
- `legacy/` - 旧版本代码（命令行版、PyQt6 版）

## 生成的文件

- 生成的PDF文件将包含指定数量的数学题目
- 支持多种题目格式：
  - 加法：`(     ) + 15 = 23` 或 `67 + (     ) = 92` 或 `67 + 15 = (     )`
  - 减法：`(     ) - 15 = 23` 或 `67 - (     ) = 29` 或 `67 - 15 = (     )`
  - 乘法：`(     ) x 6 = 42` 或 `7 x (     ) = 35` 或 `7 x 6 = (     )`
  - 除法：`(     ) ÷ 4 = 8...2` 或 `35 ÷ (     ) = 7...0` 或 `35 ÷ 4 = (     )`
  - 混合运算：`(     ) + 5 x 3 = 23` 或 `12 - (     ) ÷ 2 = 8` 或 `12 - 5 ÷ 2 = (     )`
- 使用中文全角空格确保对齐美观
- 所有题目的数字和结果都在用户设定的范围内

## 范围设置说明

### 数字范围
- 控制题目中出现的数字大小
- 范围：1-999
- 例如：设置为10-50，则题目中的数字都在10到50之间

### 结果范围
- 控制题目答案的大小
- 范围：1-999
- 例如：设置为1-100，则所有题目的答案都在1到100之间

### 智能验证
- 程序会自动验证范围设置的合理性
- 如果最小值大于最大值，会自动交换
- 确保生成的题目符合数学逻辑和设定要求
